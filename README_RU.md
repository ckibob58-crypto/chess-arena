# Chess Arena 1.2.7

Шахматное приложение для macOS Apple Silicon, Windows и браузерного запуска через Vite.

## Что изменено в 1.2.7

- **Один ответ бота на один ход игрока.** Вся логика ответа теперь находится в одной функции: она резервирует FEN до поиска, выполняет ровно один запрос движку и применяет ровно один легальный ход. Добавлено минимальное время обдумывания, чтобы ходы визуально не сливались.
- **Более мягкая оценка.** Расширены диапазоны «отличный» и «хороший», добавлен больший допуск к колебаниям Stockfish. Ложная эвристика «можно взять фигуру на поле назначения» больше не выдаёт бриллиантовый ход. Без полноценного Stockfish отрицательные очки не начисляются.
- **Скрытые варианты движка.** Возможные продолжения не видны на основной панели и находятся только в раскрываемых «Настройках движка».
- **Stockfish 19.** Два независимых Worker: один играет, другой анализирует. `npm install` копирует JS и WASM-ресурсы в `public/engine/`.
- **Сетевая игра.** Есть API аккаунтов, WebSocket-матчмейкинг, проверка ходов и рейтинг. Добавлено поле для проверки/сохранения адреса опубликованного сервера прямо из режима «Онлайн».
- **Комплект публикации сервера.** Добавлены `Dockerfile` и `render.yaml` для деплоя на Render с постоянным хранилищем.

Классификация качества — приближённая пользовательская шкала, не официальная оценка Chess.com. Если глубина и результат поиска не надёжны, ход не штрафуется.

## Быстрый запуск на Mac

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run preview
```

Открой `http://127.0.0.1:8173/preview.html`. Для Electron: `npm run dev`. Для DMG Apple Silicon: `npm run dist:mac-arm64`; готовый установщик будет в `release/`, а Vite-сборка — в `dist/`.

## Stockfish

После `npm install` должны быть созданы:

- `public/engine/stockfish-19-lite-single.js`
- `public/engine/stockfish-19-lite-single.wasm`

Если их нет, выполни `npm run copy:engine`. В шапке игры должно появиться «Stockfish 19 готов». Иначе приложение явно использует резервный поиск.

## Сетевая игра

Сервер находится в `server/server.cjs`. Для публикации используй `render.yaml` и `Dockerfile` (инструкция — `server/README_RU.md`). После появления публичного HTTPS-адреса открой режим «Онлайн», раскрой «Подключить опубликованный сервер», введи базовый адрес и проверь его. Зарегистрируй серверный аккаунт и используй его на двух устройствах. Адрес можно изменить в настройках сервера в любой момент.

**Сам сервер из этой среды не опубликован.** Поэтому удалённые матчи не могут начать работать до деплоя; локальные игры с ботом и другом не требуют сервера.

## macOS

Запусти `Build-Chess-Arena-Mac.command`. Установщик `.dmg` появится в `release/`. Сборка из исходников неподписана без Apple Developer ID/notarization.


## Версия 1.2.7

- Шестой уровень MAX на Stockfish 19 с адаптивным лимитом времени: тише позиции — короче поиск, шахи/тактика/эндшпили — дольше.
- Белые и чёрные используют разные Unicode-глифы фигур; белые фигуры имеют белую внутреннюю заливку.
- Последний ход отмечается только жёлтой рамкой, без полупрозрачной заливки клеток, поэтому доска не темнеет при ожидании ответа.


### Быстрый Preview без Node.js (версия 1.2.7)

Откройте `Open-Limited-Preview.command` двойным щелчком (при предупреждении macOS — правой кнопкой → Открыть). Скрипт использует Python 3 и локальный HTTP-сервер, поэтому для демонстрации в браузере Node.js не требуется. Stockfish Lite и chess.js в браузерном Preview загружаются из CDN, поэтому нужен интернет. Для настоящего desktop-приложения и сборки DMG Node.js 22 LTS всё ещё необходим.


## Полный режим и онлайн

Для запуска полного клиента с настоящим сетевым UI используй `Open-Chess-Arena.command` и инструкцию `START-HERE-RU.md`. Отдельный файл `preview.html` является только браузерным preview. Серверный код находится в `server/server.cjs`; для игры через интернет его нужно опубликовать через `render.yaml`.


## Полный сетевой комплект 1.2.7

Основной запуск полной версии с аккаунтами и сетевым клиентом: `Open-Chess-Arena.command` (использует лёгкий `webapp/`). Полная инструкция: `START-HERE-RU.md`. Сервер: `server/`; инструкция: `server/README_RU.md`. Публичный сервер нужно опубликовать отдельно, он не развёрнут автоматически.
