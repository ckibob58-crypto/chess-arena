# Chess Arena — сетевой сервер 1.2.7

Сервер обеспечивает общие аккаунты, уникальность ников, токены входа, рейтинг Elo, матчмейкинг по близкому рейтингу и WebSocket-партии. Все ходы проверяются на сервере через `chess.js`.

## Локальный запуск

```bash
cd server
npm install
CHESS_ARENA_SECRET="длинный-случайный-секрет" npm start
```

Проверка: `http://127.0.0.1:8787/api/health`. В корне комплекта есть `Start-Local-Multiplayer-Server.command`.

## Публикация в интернете через Render

В корне комплекта находятся `render.yaml` и `Dockerfile`. Загрузите весь комплект в GitHub, затем в Render выберите `New → Blueprint` и подключите репозиторий. Render использует `Dockerfile`, постоянный диск `/var/data` и health-check `/api/health`.

После публикации проверьте `https://ВАШ-ДОМЕН/api/health`. В JSON должно быть `ok: true` и `matchmaking: true`.

В приложении Chess Arena откройте «Онлайн» → «Настройки сервера», укажите базовый HTTPS-адрес без `/api/health`, нажмите «Проверить и сохранить сервер». Затем создайте серверный аккаунт или войдите в него на каждом устройстве и нажмите «Найти соперника».

## Маршруты

- `GET /api/health` — статус сервера и матчмейкинга.
- `POST /api/register`, `POST /api/login`, `GET /api/me` — серверные аккаунты.
- `GET /api/leaderboard` — таблица лидеров.
- `POST /api/match/ticket` — одноразовый билет для WebSocket.
- `WS /ws/match?ticket=...` — очередь, матчи, ходы, сдача и ничья.

Сервер назначает цвет, сверяет каждый ход и обновляет Elo после завершения партии. Диапазон матчмейкинга начинается примерно с ±150 Elo и постепенно расширяется при ожидании.

## Ограничения

Серверный код включён в комплект, но не размещён публично автоматически. До деплоя удалённые матчи недоступны. Переподключение к незавершённой партии и шахматные часы пока не реализованы; при отключении одного игрока партия аннулируется без рейтингового изменения. Для постоянного хранения аккаунтов нужен тариф/хостинг с persistent storage.
