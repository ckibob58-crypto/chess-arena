# Chess Arena 1.2.7 — полный комплект игры и сетевого сервера

Этот ZIP содержит **полное приложение**, а не только шахматную доску: шесть уровней бота, Stockfish 19, оценку ходов, игру вдвоём на одном устройстве, аккаунты, Elo и серверную сетевую игру.

## Быстрый запуск полной игры на Mac

Нужен Node.js 20.19+ или 22 LTS. Обычная игра в браузере не требует установленного Electron.

1. Распакуй архив.
2. Дважды нажми `Open-Chess-Arena.command` (если macOS предупреждает — правый клик по файлу → «Открыть»).
3. Скрипт перейдёт в `webapp/`, установит только React/Vite/Stockfish, скопирует файлы движка и откроет приложение по адресу `http://127.0.0.1:8173/`.
4. Оставь окно Терминала открытым, пока играешь. Чтобы остановить приложение, закрой это окно.

Это основной полный клиент — `webapp/src/App.jsx`. Отдельный `preview.html` оставлен как ограниченный быстрый Preview и не содержит всех сетевых функций.

## Режимы игры

- **С ботом:** 500, 1000, 1500, 2000, 2500 и MAX. Максимальный уровень использует Stockfish 19 с адаптивным поиском.
- **Вдвоём:** два человека играют за одним устройством.
- **Онлайн:** серверные аккаунты, очередь соперников с близким рейтингом, случайный выбор цвета, проверка ходов на сервере и обновление Elo.

В анализе есть шкала позиции, оценка качества ходов и скрытые в настройках варианты движка. В игре с ботом включение оценки стоит одну звезду на партию; в локальной игре с другом анализ бесплатный.

## Как включить игру через интернет

Сетевой клиент и сервер уже входят в ZIP. Но сервер ещё надо разместить на общедоступном HTTPS/WSS-хостинге — один HTML-файл не может самостоятельно соединить двух удалённых игроков.

1. Создай GitHub-репозиторий и загрузи туда **всё содержимое этого комплекта**, включая `Dockerfile`, `render.yaml`, `server/` и `webapp/`.
2. В Render выбери `New → Blueprint`, подключи репозиторий и подтверди создание сервиса из `render.yaml`.
3. Дождись публикации. Открой `https://ИМЯ-СЕРВИСА.onrender.com/api/health`. Должно вернуться `ok: true` и `matchmaking: true`.
4. Запусти Chess Arena на двух разных устройствах. В каждом открой «Онлайн» → «Настройки сервера», введи базовый HTTPS-адрес Render (без `/api/health`) и нажми «Проверить и сохранить сервер».
5. На обоих устройствах создай аккаунт через сервер или войди в серверный аккаунт. Локальный профиль на одном устройстве не является общим серверным аккаунтом.
6. На обоих устройствах нажми «Найти соперника». Матч начнётся после того, как сервер найдёт второго пользователя.

Полная инструкция сервера, его API и ограничения: `server/README_RU.md`.

## Проверить сервер в одной Wi‑Fi-сети

Запусти `Start-Local-Multiplayer-Server.command` на одном Mac. В настройках онлайн на другом устройстве укажи `http://LAN-IP-АДРЕС-MAC:8787`. Это только тест внутри локальной сети; для интернета нужен HTTPS/WSS и публичный хостинг.

## Готовое приложение macOS (.dmg)

Для сборки установщика открой корневой `Build-Chess-Arena-Mac.command`. Он использует desktop-пакет из корня проекта и создаёт `dist/` и `release/*.dmg`. Для сборки нужен Node.js и интернет для установки зависимостей. Готового `.dmg` в этом архиве нет.

## Честный статус

В комплекте есть клиент сетевой игры и серверная реализация. **Публичный сервер не опубликован автоматически** — это нужно сделать в Render по шагам выше. До публикации доступны игра с ботами и локальная игра вдвоём; удалённый матчмейкинг не сможет работать. npm-установка и Vite/Electron-сборка в этой среде не завершились из-за тайм-аута доступа к реестру пакетов, поэтому готовые `.dmg` и собранный `dist/` не заявляются.
